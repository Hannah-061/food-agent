# Discord Server 設定步驟（macOS）

這份文件帶你：建立自己的 Discord Server → 建立給 agent 用的頻道並拿到 `CHANNEL_ID` → 產生邀請連結給同組同學。

- 用 **Discord 桌面版** 或 **瀏覽器版（discord.com/app）** 都可以，畫面幾乎一樣。下面的步驟以 Mac 為準。
- Discord 偶爾會改版，如果某個按鈕名稱和這裡略有不同，找意思最接近的那個即可。
- 做完這份之後，接著做 [discord-bot-setup.md](discord-bot-setup.md)。

名詞：

- **Server（伺服器）**：Discord 上一個屬於你們的「聊天空間」，裡面有很多頻道。
- **頻道（Channel）**：Server 裡的一個聊天室。agent 只會看你指定的那一個頻道。
- **CHANNEL_ID**：每個頻道有一組獨一無二的數字編號，agent 靠它知道要看哪個頻道。

---

## 一、建立你自己的 Server

1. 打開 Discord，並登入你的帳號。
2. 看畫面**最左邊**那一條直的圖示列。最下面有一個 **「＋」**（綠色加號，提示文字是「新增伺服器」），點它。
3. 跳出「建立伺服器」視窗，點 **「親自創建」**（Create My Own）。
4. 下一頁問「這個伺服器是給誰用的？」，點 **「給我和我的朋友」**（For me and my friends）。
5. 下一頁：
   - 「伺服器名稱」改成你喜歡的名稱，例如 `食物日記`
   - 圖示可以不用上傳
6. 點右下角 **「建立」**。

完成後，左邊圖示列會多一個你的 Server，點進去就是它。

---

## 二、建立給 agent 用的頻道

新 Server 會自帶一個 `#一般`（general）頻道。為了讓紀錄乾淨，另外開一個專用頻道。

1. 在 Server 裡，看左邊的頻道清單。找到分類名稱 **「文字頻道」**（Text Channels），在它右邊有一個 **「＋」**，點它。
2. 跳出「建立頻道」視窗：
   - 頻道類型選 **「文字」**（Text）
   - 頻道名稱輸入 `food-photos`（Discord 會自動轉成小寫，空白變成 `-`）
   - **「私人頻道」**（Private Channel）開關**先不要打開**。保持關閉，所有 Server 成員都看得到，之後測試比較單純。
3. 點右下角 **「建立頻道」**。

左邊清單的「文字頻道」底下就會出現 `# food-photos`。

---

## 三、拿到 CHANNEL_ID

Discord 預設不會顯示編號，要先打開「開發者模式」。

### 3-1 打開開發者模式（只需要做一次）

1. 點畫面**左下角、你的大頭貼旁邊的齒輪**（使用者設定）。
2. 在左側選單往下找，點 **「進階」**（Advanced）。
3. 把 **「開發者模式」**（Developer Mode）的開關**打開**（變成綠色）。
4. 按右上角的 **「ESC」** 或 **「✕」** 關閉設定。

### 3-2 複製頻道編號

1. 在左邊的頻道清單中，對 `# food-photos` **按右鍵**（Mac 觸控板：兩指點一下；或按住 Control 再點一下）。
2. 選單最下面有 **「複製頻道 ID」**（Copy Channel ID），點它。
3. 把它貼到一個**暫時的地方**（例如備忘錄）。它是一串長長的數字，像 `1234567890123456789`。

之後會把它填進專案的 `.env`：

```
CHANNEL_ID=（貼上這串數字）
```

> `CHANNEL_ID` 不算機密，不像 bot token 那麼危險；但也不用貼到公開的地方。

---

## 四、產生邀請連結，讓同組同學加入

先做一個提醒：**拿到連結的人都可以加入你的 Server，加入後就能在頻道傳照片，而每張照片都會用掉你的 Claude 額度。** 所以連結要設定期限和人數上限，測完後也要作廢。

1. 在 Server 裡，點左上角 **Server 名稱**（有個小箭頭），會跳出選單。
2. 點 **「邀請其他人」**（Invite People）。
3. 在跳出的視窗**最下方**，點 **「編輯邀請連結」**（Edit invite link，齒輪圖示或文字連結）。
4. 設定：
   - **「到期時間」**（Expire After）：選 **7 天**
   - **「使用次數上限」**（Max Number of Uses）：選你們組的人數，例如 **5 次**
   - 「授予暫時成員資格」（Grant temporary membership）：**不要打開**
5. 點 **「產生新連結」**（Generate a New Link）。
6. 點 **「複製」**（Copy）。連結會長得像 `https://discord.gg/xxxxxxx`。
7. 把這條連結用你們組平常聊天的方式（LINE、Email 等）傳給同學。

同學點開連結後，會看到「你被邀請加入……」，按 **「接受邀請」**（Accept Invite）就會進到你的 Server，並能看到 `# food-photos`。

### 測完之後作廢連結

1. 左上角 Server 名稱 → **「伺服器設定」**（Server Settings）。
2. 左邊選單點 **「邀請」**（Invites）。
3. 在剛才那條連結右邊點 **「✕」**（撤銷）。

撤銷後，沒用過的人就進不來了；已經加入的人不受影響。
